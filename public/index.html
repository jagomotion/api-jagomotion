Layanan integrasi pengiriman surel dan perpesanan WhatsApp otomatis.

Mendeteksi URL...
Hai, dokumentasi ini aku buat seringkas dan senyaman mungkin untuk kamu integrasikan. Semua contoh cURL di bawah ini sudah otomatis mendeteksi alamat host yang sedang kamu buka (baik di Termux localhost maupun saat deploy di domain Vercel).

mail Layanan Surel (Nodemailer Clean)

POST /api/mail/otp

Kirimkan kode OTP verifikasi ke email pengguna dengan tampilan bersih minimalis.

Contoh Permintaan
curl -X POST /api/mail/otp \ -H "Content-Type: application/json" \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026" \ -d '{ "email": "user@gmail.com", "otp": "492018", "purpose": "Pendaftaran Akun Baru" }'
POST /api/mail/reset-password

Kirimkan tautan penyetelan ulang kata sandi yang bersih dan responsif.

Contoh Permintaan
curl -X POST /api/mail/reset-password \ -H "Content-Type: application/json" \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026" \ -d '{ "email": "user@gmail.com", "resetUrl": "https://jagomotion.com/reset?token=xyz123" }'
POST /api/mail/send

Kirim email kustom bebas dengan konten HTML atau teks biasa.

Contoh Permintaan
curl -X POST /api/mail/send \ -H "Content-Type: application/json" \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026" \ -d '{ "to": "user@gmail.com", "subject": "Pesanan Kamu Sedang Diproses", "html": "<p>Halo, pesanan paket #1029 sedang dalam pengiriman.</p>" }'

chat Layanan WhatsApp (Baileys Engine)

POST /api/wa/session

Hubungkan nomor bot WhatsApp baru dan dapatkan 8-digit Pairing Code.

Contoh Permintaan
curl -X POST /api/wa/session \ -H "Content-Type: application/json" \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026" \ -d '{ "number": "6283110390167" }'
POST /api/wa/send-otp

Kirim kode OTP akun langsung lewat chat WhatsApp bot yang sudah aktif.

Contoh Permintaan
curl -X POST /api/wa/send-otp \ -H "Content-Type: application/json" \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026" \ -d '{ "senderNumber": "6283110390167", "targetNumber": "6281234567890", "otp": "782103", "appName": "JagoMotion" }'
POST /api/wa/send-message

Kirim pesan chat kustom ke nomor WhatsApp pengguna.

Contoh Permintaan
curl -X POST /api/wa/send-message \ -H "Content-Type: application/json" \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026" \ -d '{ "senderNumber": "6283110390167", "targetNumber": "6281234567890", "message": "Halo! Transaksi berhasil diproses." }'
POST /api/wa/restart/:number

Gunakan endpoint ini untuk memulihkan koneksi bot secara paksa jika socket WhatsApp terasa lag atau macet.

Contoh Permintaan
curl -X POST /api/wa/restart/6283110390167 \ -H "X-API-KEY: JAGOMOTION_SECRET_KEY_2026"
